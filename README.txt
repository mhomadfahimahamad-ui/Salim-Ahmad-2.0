SALIM AHMAD 2.0
=================
1. Upload all files to a static host (GitHub Pages is free).
2. Keep index.html in the site root.
3. Open the generated URL.

FEATURES
- Automatic OCR for image documents.
- Common claim-document headings are automatically mapped to names.
- Low-confidence results are marked "Manual review".
- Names can always be edited manually.
- Named files can be downloaded as a ZIP.
- Image files can be combined into a PDF.

NOTE
PDF text extraction/first-page OCR is not included in this lightweight static build.
Original PDFs are preserved in the ZIP. Image documents receive automatic OCR.
